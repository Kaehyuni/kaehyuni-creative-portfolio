# Kaehyuni Creative Portfolio

Kenny Nguyen's creative portfolio for videography, motion graphics, animation, UX/class projects, recording engineering, and artwork.

## Development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```

The generated site is written to `dist/`.

## Deployment

The repository includes `netlify.toml` with the production build command, publish directory, and single-page app redirect used by Netlify.

## Stack

- React and TypeScript
- Vite
- Tailwind CSS and shadcn/ui
- Framer Motion
